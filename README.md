# TripManager
Manage the trips on the z&#0361;mo XT, XT2, XT3 and the Tread 2.<br>

# About TripManager
<html>
<body bgcolor="#FFFFFF">
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt">TripManager can be characterized as a <b>toolbox</b> for</span></font> <a href="https://frankbijnen.github.io/TripManager/modelinfo.html"><font face="Calibri" color="#0000FF" size="4"><span style="font-size:14pt"><u>Garmin Zumo models</u></span></font></a><font face="Calibri" color="#010101" size="4"><span style="font-size:14pt">. Targeted at models: <b>XT,&nbsp; XT2, XT3 and Tread 2</b></span></font>
  </div>
  <div align="left">
    <br>
  </div>
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt">It can transfer routes, tracks, waypoints and POI's to the Zumo using GPX files, help detect and prevent problems commonly encountered by Zumo users.</span></font>
  </div>
  <ul>
    <li style="margin-left: 1mm; margin-right: 0mm; padding-left: 0mm; font-family= Calibri; font-size= 14pt; color= #010101;">
      <div align="left">
        <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt">Shaping points that don't retain their name, or location.</span></font>
      </div>
    </li>
    <li style="margin-left: 1mm; margin-right: 0mm; padding-left: 0mm; font-family= Calibri; font-size= 14pt; color= #010101;"><font face="Calibri" color="#010101" size="4"><span style="font-size:14pt">Routes that are different from what was planned.</span></font></li>
    <li style="margin-left: 1mm; margin-right: 0mm; padding-left: 0mm; font-family= Calibri; font-size= 14pt; color= #010101;">
      <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt">Unwanted routing behaviour known as</span></font> <a href="https://zumouserforums.co.uk/app.php/ZXT-P100?.html" target="_blank"><font face="Calibri" color="#0000FF" size="4"><span style="font-size:14pt"><u>RUT</u></span></font></a><font face="Calibri" color="#010101" size="4"><span style="font-size:14pt">.</span></font>
    </li>
  </ul><br>
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt">A unique feature of TripManager is that it can read and write the trips in the trip planner directly. This enables viewing and editing information that is normally hidden to the user.</span></font>
  </div>
  <div align="left">
    <br>
  </div><font color="#010101"><br clear="all" style="page-break-before:always"></font>
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt"><b>Notes:</b></span></font>
  </div>
  <ul>
    <li style="margin-left: 1mm; margin-right: 0mm; padding-left: 0mm; font-family= Calibri; font-size= 14pt; color= #010101;">
      <div align="left">
        <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt">TripManager conforms to many of the concepts described in this document:</span></font> <a href="https://zumouserforums.co.uk/viewtopic.php?t=1464?.html" target="_blank"><font face="Calibri" color="#0000FF" size="4"><span style="font-size:14pt"><u>Zumo XT and Planned Routes - Everything That You Need to Know</u></span></font></a>
      </div>
    </li>
    <li style="margin-left: 1mm; margin-right: 0mm; padding-left: 0mm; font-family= Calibri; font-size= 14pt; color= #010101;">
      <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt">Throughout the documention here the terms <b>Way point</b>, <b>Via point</b> and <b>Shaping point</b> are used conforming to the definitions you can find here:&nbsp;</span></font> <a href="https://zumouserforums.co.uk/app.php/ZXT-P04?.html" target="_blank"><font face="Calibri" color="#0000FF" size="4"><span style="font-size:14pt"><u>Some Garmin Definitions</u></span></font></a>

# Features
<html>
<body bgcolor="#FFFFFF">
  <font face="Calibri" size="4"><span style="font-size:14pt"><b>From the</b></span></font> <a href="https://frankbijnen.github.io/TripManager/Trip%20Manager%20Users%20Guide_V1.6.pdf?.html"><font face="Calibri" color="#0000FF" size="4"><span style="font-size:14pt"><b><u>users guide</u></b></span></font></a><font face="Calibri" size="4"><span style="font-size:14pt"><b>:</b></span></font><br>
  <ul>
    <li style="margin-left: 1mm; margin-right: 0mm; padding-left: 0mm; font-family= Calibri; font-size= 14pt; font-style= italic;">
      <div align="left">
        <font face="Calibri" size="4"><span style="font-size:14pt"><i>Support for .trip, .gpx, .gpi, .kml and .html file types.</i></span></font>
      </div>
    </li>
    <li style="margin-left: 1mm; margin-right: 0mm; padding-left: 0mm; font-family= Calibri; font-size= 14pt; font-style= italic;"><font face="Calibri" size="4"><span style="font-size:14pt"><i>Enhanced file management with bi-directional file transfer between zumo and PC, multi-select support, logical file naming, organization, and grouping.</i></span></font></li>
    <li style="margin-left: 1mm; margin-right: 0mm; padding-left: 0mm; font-family= Calibri; font-size= 14pt; font-style= italic;"><font face="Calibri" size="4"><span style="font-size:14pt"><i>Automatic or easy setting of routes to “saved” rather than “imported” which prevents “RUT” behavior.</i></span></font></li>
    <li style="margin-left: 1mm; margin-right: 0mm; padding-left: 0mm; font-family= Calibri; font-size= 14pt; font-style= italic;"><font face="Calibri" size="4"><span style="font-size:14pt"><i>Detailed viewing and editing of .trip file content including an overview on an Open Street Maps (OSM) map and a detailed hexadecimal view.</i></span></font></li>
    <li style="margin-left: 1mm; margin-right: 0mm; padding-left: 0mm; font-family= Calibri; font-size= 14pt; font-style= italic;"><font face="Calibri" size="4"><span style="font-size:14pt"><i>Conversion of coordinates to addresses and vice versa.</i></span></font></li>
    <li style="margin-left: 1mm; margin-right: 0mm; padding-left: 0mm; font-family= Calibri; font-size= 14pt; font-style= italic;"><font face="Calibri" size="4"><span style="font-size:14pt"><i>Modification of trip dates, transportation modes and routing preferences.</i></span></font></li>
    <li style="margin-left: 1mm; margin-right: 0mm; padding-left: 0mm; font-family= Calibri; font-size= 14pt; font-style= italic;"><font face="Calibri" size="4"><span style="font-size:14pt"><i>Creation of .trip files on the zumo directly from .gpx files on the computer, including those created by Basecamp or other route planning software, eliminating the need to import and save routes and other data.</i></span></font></li>
    <li style="margin-left: 1mm; margin-right: 0mm; padding-left: 0mm; font-family= Calibri; font-size= 14pt; font-style= italic;"><font face="Calibri" size="4"><span style="font-size:14pt"><i>Prevention of undesired Via and Shaping point renaming.</i></span></font></li>
    <li style="margin-left: 1mm; margin-right: 0mm; padding-left: 0mm; font-family= Calibri; font-size= 14pt; font-style= italic;"><font face="Calibri" size="4"><span style="font-size:14pt"><i>Creation of .gpi (point of interest) files from .gpx files and display of .gpi file information.</i></span></font></li>
    <li style="margin-left: 1mm; margin-right: 0mm; padding-left: 0mm; font-family= Calibri; font-size= 14pt; font-style= italic;"><font face="Calibri" size="4"><span style="font-size:14pt"><i>Post-processing of .gpx files including optional prefixing of shaping point names with route information.</i></span></font></li>
    <li style="margin-left: 1mm; margin-right: 0mm; padding-left: 0mm; font-family= Calibri; font-size= 14pt; font-style= italic;"><font face="Calibri" size="4"><span style="font-size:14pt"><i>Automatic comparison and visual presentation, on an OSM map, of .trip file content on the zumo with .gpx file content on the computer. This allows a user to check that a route calculated by the zumo matches the route specified by the .gpx file.&nbsp; Any desired adjustments can be made while sitting at a computer before beginning to travel rather than on the roadside when a problem arises.</i></span></font></li>
    <li style="margin-left: 1mm; margin-right: 0mm; padding-left: 0mm; font-family= Calibri; font-size= 14pt; font-style= italic;"><font face="Calibri" size="4"><span style="font-size:14pt"><i>Routes can be shared with others using identical zumo models by directly sharing .trip files.</i></span></font><font color="#010101"><br clear="all" style="page-break-before:always"></font></li>
  </ul><br>

Allowing:</span></font>

    <font face="Calibri" size="4"><span style="font-size:14pt"><b>Translated from a post on the German</b></span></font> <a href="https://www.naviboard.de/thread/68555-tripmanager-von-frank-bijnen/?postID=561089#post561089/?" target="_blank"><font face="Calibri" color="#0000FF" size="4"><span style="font-size:14pt"><b><u>Naviboard.de</u></b></span></font></a>
  </div>
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt"><i>TripManager (TM) is (in short) a powerful (if not the most powerful) Windows program for transferring routes to Garmin navigation devices (In particular the Zumo XT,&nbsp; XT2, XT3 and Tread 2 series) and for analyzing the *.trip files used internally by these devices, which are crucial for their operation.</i></span></font>
  </div>
  <div align="left">
    <br>
  </div>
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt"><i>Since the Garmin navigation devices supported by TripManager (TM) do not internally use routes from GPX files or from BaseCamp (contrary to what is likely a widespread assumption), but instead use the *.trip files generated from them, TripManager (TM) essentially serves to “manage” these *.trip files.</i></span></font>
  </div>
  <div align="left">
    <br>
  </div>
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt"><i>With TripManager (TM), you can transfer routes from GPX files (including via drag-and-drop) directly into the navigation device in such a way that further editing within the device itself is (in principle) no longer necessary.</i></span></font>
  </div>
  <div align="left">
    <br>
  </div>
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt"><i>When using TripManager (TM), there is no need for an additional import process in the navigation device itself, since TripManager (TM) directly uses the device’s internal route format (*.trip files). For example, a GPX import that can sometimes take several minutes on the GPS unit itself can be completed in just a few seconds using TM.</i></span></font>
  </div>
  <div align="left">
    <br>
  </div>
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt"><i>In addition to the advantage of directly using Garmin’s internal trip format for routes, TripManager (TM) can also effectively prevent the (all- too-common and “unpopular”) RUT behaviour that occurs when there are deviations in the route.</i></span></font>
  </div>
  <div align="left">
    <br>
  </div>
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt"><i>Furthermore, TripManager (TM) is also ideal for listing the navigation system’s internal trips (imported routes).</i></span></font>
  </div>
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt"><i>This is a huge help for anyone experiencing Tread App synchronization issues or “orphaned routes”, because TM makes it very easy—and, above all, quite reliable—to identify duplicate trips (routes) that are causing problems.</i></span></font>
  </div>
  <div align="left">
    <br>
  </div>
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt"><i>With TM, the “Import” flag for existing routes—which is one of the causes of the RUT problem—can also be corrected directly (just as it is when transferring data using TM itself).</i></span></font>
  </div>
  <div align="left">
    <br>
  </div>
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt"><i>The routes listed in the navigation content can also be displayed directly on a selection of maps using TM for verification (or comparison with the original GPX file).</i></span></font>
  </div>
  <div align="left">
    <br>
  </div>
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt"><i>For (more experienced) users, detailed trip information—including otherwise hidden route details—is also available.</i></span></font>
  </div>
  <div align="left">
    <br>
  </div>
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt"><i>Among other things, the app offers several additional features, such as route comparison, sharing/exporting to Kurviger, viewing Explore content, settings, and the Vehicle Profile database. Another feature that should not be underestimated for all zumo XT3 or Tread 2 users is the ability to specify the vehicle profile to be used for the route directly within the TM.</i></span></font>
  </div>
  <div align="left">
    <br>
  </div>
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt"><i>I also don’t want to forget to mention the option to transfer routes in such a way that the navigation system always requires a recalculation, or that recalculation may not be necessary for routes from BaseCamp sources, or even that routes can be transferred directly in a single segment (like Track2Routes).</i></span></font>
  </div>
  <div align="left">
    <br>
  </div>
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt"><i>Another useful feature is the ability to transfer, besides the trips, also routes, tracks, and waypoints as GPX files (for import or as a backup) directly to the navigation device. There’s also an interesting feature here that allows you to create POIs directly from a GPX route.</i></span></font>
  </div>
  <div align="left">
    <br>
  </div>
  <div align="left">
    <font face="Calibri" color="#010101" size="4"><span style="font-size:14pt"><i>Unfortunately, tracks and waypoints cannot be transferred directly, but require a manual import, to the zumo XT2, zumo XT3, or Tread 2. Partly because the data is stored in hidden directories, or the structures required to display them on the device (still) involve too many unknown characteristics.</i></span></font>
