About TripManager

TripManager can be characterized as a toolbox for Garmin Zumo models. Targeted at models: XT,  XT2, XT3 and Tread 2

It can transfer routes, tracks, waypoints and POI's to the Zumo using GPX files, help detect and prevent problems commonly encountered by Zumo users.
·   Shaping points that don't retain their name, or location.
·   Routes that are different from what was planned.
·   Unwanted routing behaviour known as RUT.

A unique feature of TripManager is that it can read and write the trips in the trip planner directly. This enables viewing and editing information that is normally hidden to the user.


Notes:
·   TripManager conforms to many of the concepts described in this document: Zumo XT and Planned Routes - Everything That You Need to Know
·   Throughout the documention here the terms Way point, Via point and Shaping point are used conforming to the definitions you can find here:  Some Garmin Definitions
·   See: Zumo XT Behaviour Issues for more info on RUT, and other issues that TripManager can help you fix.

Supported models:
Fully supported models: zumo XT, XT2, XT3 and Tread 2.
Limited: Generic Garmin (220, 660, 340, 350, 390, 590, 346, 395, 595 etc): GPX and GPI files. Edge, ForeRunner: FIT files (Experimental)

Supported Operating Systems:
Windows:
At least Windows 7 or later.
Windows 10 or 11 recommended, when using the OpenStreetMap maps, or GeoCoding.
Both 32 and 64 Bits are supported, the installer will detect the platform and install the appropriate binaries.

Mac:
Users have reported that Running TripManager on a Mac is possible using Parallels Desktop. Note that it is not free software and TripManager is not affiliated with Parallels Desktop in any way.

For a free alternative on the Mac you could have a look at Oracle's VirtualBox. Note that it has yet to be confirmed that TripManager will run on the Mac version of VirtualBox.

Linux:
TripManager does not run natively on Linux. It does run well using VirtualBox. Tested on OpenSuse TumbleWeed.
Running TripManager in Wine requires tweaking. Recognising the Zumo and displaying the maps is hard to get working.
